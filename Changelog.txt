# CHANGELOG

- 2.1.6: Primary email and the complete owner section now subtract one Mautic
  grid gutter, aligning every field with tags, segments and text inputs.
- 2.1.5: Both email blocks render at the same Twig level and their native outer
  gutters are normalized to the width of every ordinary DOI form field.
- 2.1.4: Removed the extra conditional grid column so owner email fields and
  buttons align exactly with the primary native email controls.
- 2.1.3: Primary and owner email controls now use the same native Mautic
  email-send-list layout; unchecked owner settings are rendered and toggled as
  one hidden compound form row.
- 2.1.2: Primary DOI confirmation email fields are now built by Mautic's native
  EmailSendType; unchecked owner fields render hidden server-side.
- 2.1.1: Primary DOI and owner email fields now reuse Mautic's native email
  button blocks; owner fields stay hidden while the checkbox is off.
- 2.1.0: DOI form actions can optionally send a selected Mautic owner/user
  notification only after final DOI confirmation. The owner email fields stay
  hidden while the checkbox is off.
- 2.0.13: Inactive DoiReport lifecycle now hides DOI from new form action choices,
  preserves existing DOI actions as disabled builder rows, and keeps disabled
  runtime fail-closed without losing saved form action settings.
- Compatibility update for Mautic 5/6/7
- QueueBundle-based DOI processing replaced with Symfony Messenger
- Added composer constraints for mautic/core-lib ^5 || ^6 || ^7
- Updated plugin for PHP 8.1 - 8.4 compatibility

- Cleanup and completition of translations

Version 1.4.0   09.05.2022
- NEW DNC email sending
- NEW Update lead field values before/after successfull confirmation
- NEW Webhook for DOI start and finish events
- NEW Protection against malevolent email threads scanner (ACP: Advanced Thread Protection von Microsoft)
- NEW Behavioral based protection against problematic malware scanners

Version 1.3.0   22.03.2022
- Eigener DOI Report für Plugin
- Lead Felder vor und nach DOI setzen jetzt möglich
- Do not Contact wird respektiert wenn manuell gesetzt oder von Bounce, aber nicht wenn er vom Benutzer kommt
- In den Lead Update Felder können die Platzhalter %ip% und %timestamp% genutzt werden (z.B. für DOI Logging in Lead Feldern)
