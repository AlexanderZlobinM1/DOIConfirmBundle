# DOI email route matrix

This matrix documents the complete link chain owned or used by
DOIConfirmBundle 3.0.5 when Mautic sends the selected confirmation email.
Mautic 7.2.2 source ref `f28a0120d715a441b7a6e4a688076bd7e725c862`
is the route-group reference. AuthGuard 7.2.5 ref
`ccba5823e54f3f14299a572b4283b0b129d646f1` is the MFA reference.

AuthGuard has no URL allowlist in this contract. It reads Mautic's native
access map: `public` routes pass unchanged, while authenticated Mautic routes
receive an MFA challenge only after native authentication.

| Stage | Route | Origin | In an email | Anonymous | Logged in, MFA pending | MFA satisfied |
| --- | --- | --- | --- | --- | --- | --- |
| Mautic click tracking | `/r/{redirectId}?ct=...` | Mautic `public` | Wraps a link when tracking is enabled | Follow stored redirect | Follow stored redirect; no MFA | Follow stored redirect |
| DOI confirmation | `/doi/{enc}` | Plugin `public` | `{doi_url}`, directly or behind `/r` | Process DOI, then 302 | Process DOI, then 302; no MFA | Process DOI, then 302 |
| Scanner trap | `/nothuman/{hash}` | Plugin `public` | Optional `{doi_nothuman}`, directly or behind `/r` | 200 trap response | 200; no MFA | 200 |
| Open tracking | `/email/{idHash}.gif?ct=...` | Mautic `public` | Automatic tracking pixel when enabled | Image response | Image response; no MFA | Image response |
| Browser view | `/email/view/{idHash}` | Mautic `public` | Only when selected template uses the Mautic token | Public view | Public view; no MFA | Public view |
| Unsubscribe | `/email/unsubscribe/...` | Mautic `public` | Only when selected template uses the Mautic token | Public flow | Public flow; no MFA | Public flow |
| Unsubscribe all | `/email/dnc/...` | Mautic `public` | Only when selected template uses the Mautic token | Public flow | Public flow; no MFA | Public flow |
| Local success | `/form/{id}` | Mautic `public` | Encrypted target reached after DOI, not a separate token | Public form | Public form; no MFA | Public form |
| External success | Explicit configured URL | External | Encrypted target reached after DOI | Unchanged 302 target | Unchanged 302 target | Unchanged 302 target |
| Admin preview control | `/s/forms/preview/{id}` | Mautic `main` | Must not occur in a new DOI success payload | Native login | `/s/gauth` | Admin preview |
| Plugin help control | `/s/doi-confirm/documentation` | Plugin `main` | Never | Native login | `/s/gauth` | Authorized admin only |

The expected tracked confirmation chain is:

```text
/r/{redirectId}?ct=... -> /doi/{enc} -> /form/{id}
```

With click tracking disabled it is:

```text
/doi/{enc} -> /form/{id}
```

An explicit external success URL replaces only the last stage and remains
unchanged. The optional scanner link follows the same direct-or-tracked rule
but ends at `/nothuman/{hash}`.

No public stage may redirect to `/s/login`, `/s/gauth` or
`/s/forms/preview/{id}`. Conversely, the admin preview must remain protected;
the plugin fixes the newly encrypted target instead of weakening that route.

The selected Mautic email template may contain other arbitrary or native
tokens. Those are not generated by DOIConfirmBundle and retain their native
Mautic access classification.

Regression command against an unpacked Mautic source tree:

```bash
php Tests/email-route-matrix.php /path/to/mautic
```

The check verifies the plugin token/route wiring, the absence of any AuthGuard
dependency, and Mautic's native route groups for `/r`, `/email/*`, `/form/{id}`
and the protected `/s/forms/preview/{id}` control.
